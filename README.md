# First Project - CRUD API Testing with Postman

This project demonstrates a complete CRUD workflow using Postman and REST API.

## Implementation Steps
* **Step 1:** Create environment and add variables
* **Step 2:** Create collection for E-Commerce API project
* **Step 3:** Add Login request to generate token
* **Step 4:** Add scripts to extract token from response
* **Step 5:** Add GET requests
* **Step 6:** Add Authorization header with Bearer token
* **Step 7:** Add POST requests
* **Step 8:** Save product ID for dynamic data usage
* **Step 9:** Run functional tests via Collection Runner

## Included Tests

### Positive Tests
* **GET** - Read resource data
* **POST** - Create new resource

* **Postman**
